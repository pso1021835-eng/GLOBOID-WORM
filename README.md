# 장구형 웜감속기 설계실

[설계실 열기](https://pso1021835-eng.github.io/GLOBOID-WORM/) · [유성감속기 설계실](https://pso1021835-eng.github.io/PLANETARY-GEAR/)

장구형 웜과 웜휠의 제원, 중앙 단면, 틸트 피벗에 따른 축 배치와 치면 기준 정격을 함께 살펴보는 한국어 설계 도구입니다. 제원은 현재 브라우저에 저장됩니다.

## 계산 범위

ANSI/AGMA 6135-A02의 Hindley형 초기 치수 비례와 식 (27), (28)을 사용합니다. 계수는 선택한 기준점 사이의 선형 보간값입니다. 출력토크는 입력한 효율과 서비스계수를 반영한 추정치이며 열용량, 축 및 베어링 강도는 별도 검토 대상입니다. 3D 치면은 근사 형상입니다. 틸트 상태에서는 치면 정격을 보류합니다.

## 실행

이 디렉터리를 정적 HTTP 서버로 제공하면 빌드 없이 실행됩니다. GitHub Pages는 main 브랜치의 루트를 사용합니다. Three.js r160 및 부속 모듈의 라이선스는 vendor/LICENSE.txt에 포함돼 있습니다.
